# 🚀 AI Coding Workspace

An AI-powered coding environment that enables developers to create, edit, improve, and preview applications with the help of an integrated AI assistant.

This project provides a modern developer workspace experience combining project management, file editing, AI code assistance, and live preview functionality in one platform.

---

# 🌟 Features

## 🔐 Authentication System

- User registration and login
- Secure JWT-based authentication
- Protected AI assistant access
- User-specific project management


## 📂 Project Management

Users can create and manage different types of projects:

- Website Builder
- JavaScript Workspace
- Python Workspace

Features:

- Create new projects
- Open existing projects
- Manage project files
- Store project data securely 


## 💻 Code Editor Workspace

The workspace provides:

- File explorer
- Code editing environment
- File creation
- File saving
- Project-based code management

Supported files:

- HTML
- CSS
- JavaScript
- Python


## 🤖 AI Coding Assistant

Integrated AI assistant helps developers with:

- Code generation
- Code improvement
- Debugging
- Error explanation
- Programming guidance
- Project analysis

The AI assistant understands project files and provides context-aware responses.


## ⚡ AI Code Application

Users can:

1. Ask AI to generate or improve code
2. Receive AI-generated solutions
3. Apply AI code directly into the editor


## 🌐 Live Preview

Website Builder projects support:

- Real-time HTML preview
- CSS styling rendering
- JavaScript execution
- Instant website testing
